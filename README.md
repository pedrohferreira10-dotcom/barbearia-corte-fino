# Corte Fino — Barbearia Clássica

Projeto INICIAL (HTML pronto, CSS de layout para você escrever) de **Layout com Flexbox e CSS Grid** (UC Linguagem de Marcação, SENAI-SP).

## Estrutura

```
index.html        página única (HTML completo)
css/base.css      reset, variáveis, tipografia, botões
css/flexbox.css   Parte 1: topo, hero, serviços, planos, rodapé
css/grid.css      Parte 2: galeria bento, ambiente, equipe, agenda
img/              imagens do site
```

## Como abrir
Abra o `index.html` no VS Code e use **Open with Live Server** (ou dê dois cliques no arquivo).

## Fontes
Playfair Display e Montserrat, carregadas do Google Fonts (precisa de internet; sem ela o navegador usa fontes padrão).

## Publicação (GitHub Desktop)
1. Escreva a mensagem em **Summary**
2. Clique em **Commit to main**
3. Primeira vez: **Publish repository** · Depois: **Push origin**
